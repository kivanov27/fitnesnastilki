A full-stack web application built with Next.js for FitnesNastilki, delivering a modern and scalable platform tailored to the company’s needs.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
